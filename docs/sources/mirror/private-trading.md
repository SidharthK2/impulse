## Private TradingCopy as Markdown
Users can opt into private trading, which we refer to as Stealth Mode in the UI. With Stealth Mode enabled, a user's order placements are not published to the public transaction log, and their orders are hidden from the public order book as well. In addition, all of their executions are anonymized, protecting privacy while preserving transparent prices and volume. This is the level of privacy users have come to expect in tradfi, now available in DeFi at scale for the first time.
